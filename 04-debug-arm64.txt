# Layer 04 (debug line core, arm64: Hi3798MV200H).
#
# Recipe: alldefconfig base + 01-arch-arm64.txt + 02-select-y.txt + this file ->
# olddefconfig. Fully decoupled from the distribution baseline;
# 03-convenience.txt is not applied (none of it is dtb-required).
# Build targets: Image + board dtbs; boot over tftp, debug through the serial
# console, /dev/mem and debugfs.
#
# Writing rule: comments on their own lines; CONFIG lines never carry trailing
# inline comments (merge/verification match whole lines).

# --- optimization posture, deselected ---
# -Os flipped back to -O2. LD_DEAD_CODE_DATA_ELIMINATION is not spelled out
# here: arm64 has no HAVE_LD_DEAD_CODE_DATA_ELIMINATION, the symbol is
# invisible and "off" holds by absence (measured: the arm32 equivalent had to
# be deselected explicitly -- see 90-debug-arm.txt).
# CONFIG_CC_OPTIMIZE_FOR_SIZE is not set
